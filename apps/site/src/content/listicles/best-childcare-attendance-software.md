### Quick recommendation

PebbleDesk is the best fit for licensed centers that need attendance records to support licensing reviews and subsidy billing. It keeps time-stamped, room-level records connected to CCDF workflows. Procare fits larger programs with complex state-specific reporting needs, Brightwheel fits centers prioritizing family check-in experience, and generic attendance tools fit programs that can still handle compliance documentation separately.

### How we evaluated

We evaluated childcare attendance tools on time-stamped records, room-level tracking, licensing documentation, subsidy billing support, and price transparency. Published prices are listed where available. If pricing is not public, we mark the tool as quote-required rather than estimating a monthly cost.

When a state licensing inspector asks for attendance records, they're not asking for the parent notification log. They want time-stamped, room-level documentation that shows exactly which children were in which classroom on a given day, for how long, and with what staff coverage. That documentation has to be accurate, retained for the required period, and retrievable quickly: inspections aren't always scheduled in advance.

The same attendance data drives a second, distinct compliance requirement: CCDF subsidy reimbursement. State agencies that administer childcare subsidies reimburse licensed providers based on the authorized attendance of subsidized children. The attendance record isn't just a log: it's the source document for the reimbursement claim. If the attendance record and the reimbursement claim don't match, that's a reconciliation problem that can result in a clawback.

Most childcare attendance software generates records for parents. Fewer generate records for auditors. For licensed centers with CCDF enrollment, the gap between parent-facing attendance tracking and compliance-grade documentation is where audit exposure lives.

### What compliance-grade attendance tracking requires

The attendance features most platforms highlight, QR code check-in, parent notifications, daily reports, are designed for parent communication and operational convenience. These are useful features. They're not the same as compliance documentation.

For state licensing purposes, compliance-grade attendance records need: a time-stamped entry and exit for each child, recorded at the room level (not just facility-level), with staff identification associated with the record, maintained for the state-required retention period, and exportable in a format the licensing agency will accept during an inspection.

For CCDF reimbursement purposes, attendance records need to: identify which children have active voucher authorizations, track attendance against authorized hours by day, generate documentation that maps to reimbursement claims, and be exportable in a format the subsidy agency accepts during a compliance review.

Software that generates one of these without the other creates a documentation gap that directors fill manually: usually with a second spreadsheet that duplicates work already done in the software.

### Procare: most established compliance documentation

Procare is the legacy standard for compliance-grade attendance documentation. The reporting formats have been developed over time to satisfy state licensing agencies in multiple states, and the CCDF reimbursement documentation has handled a range of state-specific requirements. Auditors familiar with the childcare software market recognize Procare's reports.

The barriers are pricing visibility and interface complexity. Procare does not publish standard pricing. The desktop-first architecture means daily attendance operations can be slower than on modern platforms, and staff training takes longer. For programs with complex, state-specific compliance documentation requirements or high audit frequency where Procare's track record matters, the quote process may be justified. Programs comparing Procare and PebbleDesk on compliance documentation specifically should verify whether Procare covers requirements that PebbleDesk's documentation does not.

### Brightwheel: parent-facing attendance, limited compliance depth

Brightwheel's check-in/check-out experience is well-designed for families: QR codes, PIN entry, parent notifications. The time-stamped records it generates are the correct underlying data for licensing compliance.

The gap is documentation format. Brightwheel's attendance records are designed for parent communication and operational visibility. Before relying on Brightwheel for licensing audits, ask for an export demo using your state's inspection checklist and confirm whether staff need to reformat the data before presenting it to inspectors. CCDF reimbursement documentation typically requires more structure than Brightwheel's attendance export provides, leaving centers to reconcile attendance and billing records manually.

For programs where attendance documentation is primarily a parent-facing feature and compliance documentation requirements are simple, Brightwheel is functional. For programs with significant CCDF enrollment or frequent audit exposure, the documentation gap creates ongoing administrative work.

### Tadpoles: parent communication, not compliance

Tadpoles is a parent communication platform with attendance features built around daily reports and parent notification. The basic tier is free, which makes it a starting point for small programs.

It is not positioned for licensing compliance documentation or CCDF reimbursement records. Programs using Tadpoles for attendance maintain their compliance documentation separately: in paper sign-in sheets, spreadsheets, or state agency portals. Tadpoles provides no billing integration, no subsidy reconciliation, and no documentation format designed for auditors. For programs with any CCDF enrollment, it's not a viable primary attendance system.

### Sandbox: clean interface, limited compliance depth

Sandbox offers a modern, clean interface with digital check-in/check-out. The platform is easy for staff to operate with a low training burden.

Compliance documentation depth is limited: the platform isn't designed for the specific export formats that state licensing agencies and CCDF subsidy reimbursement programs require. Ratio tracking is absent. For programs evaluating Sandbox on ease of use, the interface is genuinely better than older platforms. For programs evaluating on compliance documentation, it's not positioned for the use case.
