Key Patterns

  • Auth middleware — resolves session cookie → user → active membership → injects center_id and role into Hono context. Every route after auth automatically scopes to the user's center.
  • Permission middleware — requireRole('owner'), requireRole('director') etc. Checks membership role against route requirements.
  • Validation — Zod schemas from packages/shared validate all request bodies. Hono's zValidator middleware.
  • Audit logging — middleware that logs all mutations to audit_log with before/after JSONB diff.
  • Error handling — global Hono error handler returns consistent JSON error responses with status codes.
