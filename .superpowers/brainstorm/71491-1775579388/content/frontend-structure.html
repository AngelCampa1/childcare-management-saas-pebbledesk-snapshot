Key Frontend Patterns

  • TanStack Router — file-based routing, type-safe route params, route-level data loading
  • TanStack Query — all API calls go through query hooks. refetchInterval: 15000 on ratio queries for polling.
  • Auth guard — root authenticated layout checks session via TanStack Query. Redirects to /login if no session.
  • Role-based UI — sidebar items and page access filtered by user's role. Staff sees only their classroom + attendance. Directors see everything except billing/settings. Owners see all.
  • Shadcn/UI — data tables, forms, dialogs, command palette, toasts. New-york style from packages/ui.
  • API client — typed fetch wrapper using Hono's RPC client (hc) for end-to-end type safety from API routes to React components.
