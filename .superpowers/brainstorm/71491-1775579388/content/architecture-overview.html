Key Decisions

  • apps/web → React + Vite + TanStack Router + TanStack Query, deployed to Cloudflare Pages
  • apps/api → Hono on Cloudflare Workers, Better Auth mounted as middleware, Drizzle ORM
  • packages/db → Drizzle schema + Neon client, shared by API (and future cron workers)
  • packages/auth → Better Auth config with email+password and Google OAuth, shared by API and web
  • packages/shared → Zod schemas for API request/response validation, TypeScript types, domain constants (role enums, ratio limits)
  • packages/ui → Shadcn/UI components (new-york style), Tailwind CSS 4 config, shared design tokens
  • Cloudflare Hyperdrive → connection pooling between Workers and Neon
  • Row-level tenancy → every table has center_id, all queries filter by it
  • Polling → dashboard fetches ratios every 10-30s via TanStack Query refetchInterval
